## How to Update Content (GitHub Web)
1. Open the file you want to update (example: `about.html`)
2. Click the pencil icon **Edit**
3. Make changes
4. Click **Commit changes**

## Notes / Common Fixes
- If the site looks unstyled, confirm `css/styles.css` exists and HTML links to it:
  `<link rel="stylesheet" href="css/styles.css" />`
- GitHub Pages is case-sensitive. Folder/file names must match exactly.
